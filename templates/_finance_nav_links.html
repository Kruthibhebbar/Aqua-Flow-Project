{#- Reusable Finance navigation (include inside any finance-related page's header). The Dashboard control is a plain pointing at the admin_dashboard endpoint. It deliberately does NOT use history.back(), history.go(), document.referrer or any JavaScript, so it takes the admin to the Dashboard in ONE click no matter how many finance pages were opened before it, how they were reached (link, form post, redirect) or whether the page was refreshed. Optional variables set by the including page: finance_nav_current : 'finance' | 'transactions' | 'receipt' | '' (hides the self-link) finance_nav_extra : false to show only Dashboard + Finance Management -#} {%- set _cur = finance_nav_current|default('') -%} {%- set _extra = finance_nav_extra|default(true) -%} Dashboard {%- if _cur != 'finance' %} Finance Management {%- endif %} {%- if _extra %} Driver Management {%- if _cur != 'transactions' %} Transactions {%- endif %} {%- endif %}
